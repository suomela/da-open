# DA Open

This is a repository of precise formulations of ***major open questions*** related to the field of ***distributed algorithms***.

The idea is that each file is a self-contained, complete, precise formulation of the problem, and there are no obvious loopholes that would admit trivial answers.

All of the questions are such that GPT-6 in Codex has ***not*** been able to solve them within a reasonable amount of time.

## Problem index

- [One cycle versus two in massively parallel computation](questions/1-cycle-2-cycle.md)
- [Distributed versus centralized matrix multiplication](questions/matrix-multiplication.md)
- [Round-elimination fixed points for hard input-free problems on regular trees](questions/round-elimination.md)
- [The degree dependence of deterministic LOCAL vertex coloring](questions/vertex-coloring.md)
